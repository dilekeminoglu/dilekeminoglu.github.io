Frequently Asked Questions

The things people ask most about MD Preview.

What is MD Preview?

MD Preview is a viewer and editor that shows Markdown (.md) files beautifully formatted instead of raw text. It runs on Mac, iPhone and iPad.

How do I open a .md file?

Open the file with MD Preview from Files or Finder, or set MD Preview as your default Markdown app.

Is MD Preview free?

Yes, MD Preview is free.

Does it work offline?

Yes, it is offline by default. Your documents are processed on your device and never leave it; document names and contents are never collected. The app uses the internet only to load remote images inside a document and to send anonymous usage statistics (Google Firebase) that help improve the app.

Can I export to PDF?

Yes. You can turn any Markdown document into a clean PDF.

Can I edit documents?

Yes. A split-screen live editor shows an instant preview as you type, and auto-refreshes when the file changes.

Which platforms are supported?

MD Preview runs on macOS 14.6 and later, as well as iPhone and iPad.

Which Markdown features are supported?

Rich Markdown including headings, aligned tables, task lists, footnotes, definition lists, highlight, subscript/superscript, emoji shortcodes, code blocks, blockquotes and images.
